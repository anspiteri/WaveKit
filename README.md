# 🎧 WaveKit
## A Tiny Systems Audio Library

**WaveKit** is a tiny audio library, made for the purpose of improving my systems understanding and C programming skills.

For me, the key ideas I'm interested in exploring are:
- Library design & distribution
- Low-level audio manipulation and processing

At present it features some basic albeit rough functionality but the goal is to improve on this and expand.

These current features include:
- Core track utilities such as cut, paste, delete
- File I/O for .wav files at a fixed sample rate and bit depth
- Fun cross-correlation algorithm for detecting sound snippets in other audio tracks
